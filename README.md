# Smart Commerce & Admin Suite

A high-performance, full-stack Point of Sale (POS) and E-commerce application built with React and TypeScript. This platform provides a seamless bridge between a customer-facing storefront and a powerful administrative command center.

## 🚀 Key Features

### 1. Customer Storefront
*   **Dynamic Catalog**: A polished, responsive product display with category filtering.
*   **Advanced Cart System**: Real-time price calculations, quantity adjustments, and secure state management.
*   **Flexible Checkout**: Multi-channel payment support including:
    *   Cash on Delivery (COD) with verification.
    *   Direct UPI Transfers with manual verification workflows.
    *   QR Code Scanning for instant mobile payments.

### 2. Admin Command Suite
*   **Unified Dashboard**: Real-time overview of sales performance, active orders, and inventory health.
*   **Product Management**: Tools to add, edit, and categorize inventory with ease.
*   **Order Tracking**: Comprehensive lifecycle management from "Pending" to "Delivered" and "Cancelled."
*   **Batch Printing**: Integrated Print Center for generating invoices and order reports.
*   **Reporting & Analytics**: Data-driven insights to monitor shop growth and trends.

### 3. Design & UX
*   **Optimized for Screen Fit**: A "fit-to-screen" layout strategy ensures the UI maximizes workspace efficiency on all devices.
*   **Minimized Admin UI**: A streamlined header and footer design for the admin workspace to focus on core tasks.
*   **Mobile-First Response**: Fully fluid design using Tailwind CSS, ensuring accessibility on smartphones, tablets, and desktops.

## 🛠️ Tech Stack
*   **Framework**: React 18+
*   **Language**: TypeScript (for strict type safety)
*   **Build Tool**: Vite
*   **Styling**: Tailwind CSS
*   **Icons**: Lucide React
*   **Animations**: Motion
